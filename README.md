# UrbanLadder Automation Project

##  Overview
Automated testing of UrbanLadder web application using Selenium WebDriver with Page Object Model.

##  Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Apache POI
- Maven

##  Features Automated
- Alert Handling
- Drag and Drop
- Search Functionality
- Extracting Menu Items
- Form Filling
- Scroll Operations
- Warning Message Validation

##  Framework
- Page Object Model (POM)
- Data-Driven Testing (Apache POI)

##  Execution Steps
1. Clone repo
2. Import as Maven project
3. Run `testng.xml`
